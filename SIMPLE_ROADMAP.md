# Couchlist Simple Roadmap

This is intentionally short. Do not build everything at once.

## Stable now
- Discord sign-in
- anime, movie and TV tracking
- Watching / Completed / Plan to Watch
- ratings and episode progress
- Couchlist friends
- taste comparison
- Watch Together
- optional Discord community hubs
- Railway/PostgreSQL deployment

## Safe polish
- PWA install support ✅
- action confirmation messages ✅
- one-decimal ratings ✅
- first-use guide + global discovery ✅
- clearer Discord community cards ✅
- metadata freshness improvements
- friend decline/remove/block
- AniList import

## Next social feature
Simple Watch Parties:

1. choose a title
2. invite friends or a community
3. optional time
4. create party
5. members join/leave
6. when active, participants can appear as Live
7. if it is a community party, show the server name

No episode form. No synchronized video. No streaming-service automation.

## Community perks after that
- server trending
- most wanted
- simple server suggestions
- community watch parties

## Later only if users actually ask
- manga
- push notifications
- streaming availability
- richer activity signals

Avoid large rewrites, AI recommendation systems, XP/economies, chat systems and fragile integrations.
