# Couchlist Design Direction

Reference: `couchlist-ui-direction.png`

Keep the existing Couchlist information architecture. The reference is for **tone**, not permission to rebuild every page from scratch.

## Permanent feel
- dark navy / charcoal base
- cozy couch-night atmosphere
- rounded, slightly playful shapes
- bright but restrained blue accent
- simple cards with generous spacing
- relaxed copy rather than corporate dashboard language
- media posters provide most of the bright color

## People
Real Couchlist users always use their Discord avatar when one exists. The illustrated couch character is brand/hero art only; never replace real profile pictures with generated avatars.

## What to avoid
- frequent redesigns
- huge dashboards
- tiny dense controls
- orange/pink theme drift
- generic SaaS visuals
- overly cute / childish decoration
- fake user avatars when Discord already provides one
